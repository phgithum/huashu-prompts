【客服话术 OCR 助手 v2 - 使用说明】

1. 安装依赖（首次）：
   pip install -r requirements.txt

2. 运行：
   python huashu_ocr_v2.py

3. 首次运行会弹【标定向导】（全屏半透明，按顺序框 3 个区域）：
   ① 框选【聊天消息区域】= 顾客+客服消息所在的区域，拖拽后按回车
   ② 框选【顶部顾客名区域】= 能显示当前顾客名字的一小条，回车
   ③ 【点击输入框】= 在工作台输入框上点一下，回车
   标定一次，之后自动保存（huashu_ocr_config.json）

4. 使用：
   - 在工作台按 F8 或鼠标侧键 → 自动截图识别 → 生成话术 → 自动填入输入框
   - 你瞄一眼，人工确认后手动点发送（绝不自动发送！）
   - 窗口顶部可手动切换/移除顾客

5. 颜色打标签：蓝底=客服、白底=顾客，左右位置辅助
   识别不了的灰条（系统消息）自动跳过
