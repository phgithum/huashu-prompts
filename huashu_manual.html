🚀 快速开始（3 步）

1
填 API Key：往下滚到「设置」区，填入 DeepSeek API Key（没有的话看下文「申请 API」），点保存。想用免费兜底就再填智谱 Key。
2
选场景：点顶部场景按钮（被骗 / 赌博 / 限制），再选子选项（举报前 / 举报后 / 成立不退…）。
3
生成话术：把顾客原话粘进输入框，点生成话术（或按 F8 / 鼠标中键），生成完自动复制，回客服窗口 Ctrl+V 发出。

🎯 场景怎么选

场景子选项什么时候用
被骗📝 举报前顾客刚说被骗，还没在支付宝举报
⏳ 举报后顾客已提交举报，在等结果
❌ 没通过举报审核没通过（很遗憾这次没通过）
⚖️ 成立不退举报成立但对方一直不退款（最急的场景）
赌博—（无子选项）涉赌被限制的账户，只能安抚让顾客慢慢接受
限制🔓 可解除账户还能部分支出、有申诉入口
🔒 无法解除申诉失败/无法申诉，完全不能用
💡 拿不准选哪个：完全不能支付/提现 → 无法解除；还能部分支出或有申诉入口 → 可解除。

☑️ 勾选项

  • 已举报 / 举报成立：勾上后 AI 不会再问举报细节，直接进入安抚+讲结果+给路径。
  • 😤 顾客情绪激动（可叠加）：勾上后生成的话术会先稳住情绪、不展开细节，先接住再办事。

⚡ 生成话术的 4 种方式

方式操作说明
点按钮点生成话术最基础，生成完自动复制
键盘按 F8相当于点生成按钮
鼠标中键按鼠标中键（滚轮按下）侧键可映射成中键用
自动感应开启⚡自动感应复制顾客消息（Ctrl+C）→ 切回本页 → 自动检测剪贴板 → 自动生成
✅ 生成完自动复制到剪贴板，直接 Ctrl+V 就能发。发送永远人工，不自动发。

🔑 申请 API（两个平台）

1️⃣ DeepSeek（主力，质量最稳）

  1. 打开 platform.deepseek.com，手机号注册登录
  2. 左侧菜单「API Keys」→ 点「创建 API Key」→ 复制生成的 Key（格式 sk-...）
  3. 左侧「充值」：充 10 块钱能用很久（生成一次话术约 1 分钱不到）
  4. 把 Key 填进小助手设置区「API Key」，点保存
💡 余额可在设置区点「查用量 ↗」跳官网查看；页面「余额」处也会显示。

2️⃣ 智谱 GLM（免费兜底）

  1. 打开 open.bigmodel.cn，注册登录（需实名认证）
  2. 「API Keys」→ 创建 Key（格式 xxxx.xxxx）
  3. 选 glm-4-flash 模型 = 完全免费，不花钱
  4. 填进设置区「智谱 API Key」，保存
✅ 提供方选「自动」= 主力 DeepSeek 挂了/超时，自动切免费智谱兜底，不耽误干活。

⚙️ 设置区详解

项目说明
API 提供方DeepSeek（主力）/ 自动（DS优先，挂了切免费GLM）/ 智谱GLM（免费）
模型DS：v4-flash（快省推荐）/ v4-pro（更强稍慢）；智谱：glm-4-flash（免费稳定）/ glm-4.7-flash（免费易限流）
余额DeepSeek 余额显示 + 「查用量 ↗」跳官网
规则来源显示当前用的是「内置规则」还是「云端规则」（云端会自动更新，不用管）
导出话术记录一键把「顾客原话+生成话术+场景+时间」导出成 JSON 文件，攒真实数据用
清除清掉本机保存的 API Key

💬 其他小功能

  • 💕 人文关怀：点一下，自动按当前时间段生成一句生活关怀语（深夜提醒早睡、饭点提醒吃饭…），追加到话术末尾，让回复更像真人。
  • 转接关键词：输入框输入「转接 / 转交」→ 直接生成转接话术（预置模板，不调 API、不花钱）。
  • 清空：清空输入框和话术区。

📱 网页版 vs 本地版

网页版（本页）本地版（电脑脚本）
地址/文件网页直接打开huashu_assistant_gui.py 双击运行
自动感应✅ 支持（需 HTTPS）❌ 不支持
截图OCR❌ 不支持✅ 支持（F8 截工作台）
API Key 存放浏览器本地电脑本地
⚠️ 网页版和本地版的 Key 是分开存的，网页版首次用要重新填一次。

❓ 常见问题

  • API 选项/模型/余额按钮不见了？ → 页面被缓存成旧版了，强制刷新（手机清缓存 / 电脑 Ctrl+F5）。
  • 自动感应没反应？ → 自动感应只在网页版（HTTPS）可用，且浏览器要允许剪贴板权限；太短的文字、跟上次相同的文字不会触发。
  • Key 会泄露吗？ → Key 只存在你自己浏览器里，源码里没有，别人访问不到。
  • 生成的话术偏软/偏硬？ → 场景子选项要选对（成立不退、情绪激动这些会改变话术方向）；还不对就反馈调整规则。
  • 会替我把消息发出去吗？ → 永远不会。生成完只复制到剪贴板，发送必须人工点。这是红线。
