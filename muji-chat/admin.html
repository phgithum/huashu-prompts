使用说明

1. 用户打开对话页时，页面顶部会显示他的「设备编号」，让用户复制发给你；
2. 你在上面添加/拉黑后点「保存并生效」，用户刷新页面立即生效；
3. 白名单模式下，不在名单里的设备全部显示「此设备已被禁用」；
4. 名单保存在仓库 muji-chat/acl.json，改动会留有 git 记录。
